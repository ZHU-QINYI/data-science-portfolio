## What this site is

A portfolio documenting one completed data science project end to end:

> **Can body measurements predict penguin species?**
> Given only a penguin's bill length, bill depth, flipper length and body mass,
> can we identify its species — and which measurement carries the most
> information?

The project itself lives in a separate repository:
**[ZHU-QINYI/data-science-project](https://github.com/ZHU-QINYI/data-science-project)**

**Author:** ZHU Qinyi (MC64890) · CISC7204 Practice 09, City University of Macau

## How this site is built

`index.md` in the repository root is the website entry file. GitHub Pages
builds it with Jekyll using the `jekyll-theme-cayman` theme, configured in
`_config.yml`.

Pages settings used: **Deploy from a branch** → branch `main` → folder `/ (root)`.

### Preview locally (optional)

```bash
bundle install
bundle exec jekyll serve
# then open http://127.0.0.1:4000
```

### Repository layout

```
data-science-portfolio/
├── index.md          ← the website itself (Pages entry file)
├── _config.yml       ← Jekyll / theme configuration
├── Gemfile           ← local preview dependencies
├── assets/           ← figures referenced by index.md
│   ├── fig1_dataset_overview.png
│   ├── fig2_bill_scatter.png
│   ├── fig3_size_by_species.png
│   └── fig5_model_performance.png
└── .gitignore
```

Every number and figure on the site is generated by running `analysis.py` in
the project repository — nothing is typed in by hand.
